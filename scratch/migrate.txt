1. Go to https://supabase.com and create a new project.
2. In your new Supabase project, go to **Project Settings -> Database** and find your **Connection string** (URI).
   Make sure you replace `[YOUR-PASSWORD]` with your actual database password.
3. Open your terminal in this project folder and run the following command to apply all migrations to your new database:

   npx supabase db push --db-url "postgresql://postgres.[YOUR_PROJECT_ID]:[YOUR_PASSWORD]@aws-0-[REGION].pooler.supabase.com:6543/postgres"

4. Go to **Project Settings -> API** and copy your **Project URL**, **anon public key**, and **service_role key**.
5. Update your `.env` file with these new values:
   SUPABASE_PROJECT_ID="your_new_project_id"
   SUPABASE_URL="your_new_project_url"
   SUPABASE_PUBLISHABLE_KEY="your_new_anon_key"
   VITE_SUPABASE_PROJECT_ID="your_new_project_id"
   VITE_SUPABASE_URL="your_new_project_url"
   VITE_SUPABASE_PUBLISHABLE_KEY="your_new_anon_key"
   SUPABASE_SERVICE_ROLE_KEY="your_new_service_role_key"
